# 写真台帳

設計事務所の工事写真台帳を作るための、ブラウザだけで完結するWebアプリです。サーバーは不要で、社内サーバーでも Vercel のような静的ホスティングでも、ローカルで `npm run dev` して開くだけでも使えます。

## できること

- **ドラッグ&ドロップで取り込み**：写真（フォルダごとも可）をドロップするだけで台帳に追加されます。
- **iPhoneのHEIC/HEIF対応**：拡張子の違いで表示できない `.heic` / `.heif` は、取り込み時に自動でJPEGへ変換します。
- **撮影日の自動取得**：EXIFの撮影日時を読み取り、無ければファイルの更新日時を使います。
- **物件名の自動入力**：フォルダごとドロップすると、フォルダ名がそのまま物件名になります（既存の物件名と一致すれば統合されます）。
- **説明文の初期値を自動生成**：ファイル名から簡易的に説明文の初期値を作ります（例: `01_外壁_南面.jpg` → `外壁 南面`）。手動で自由に編集できます。
- **ステータス（工程）・メモ管理**：写真ごとに工程（敷地現況写真、基礎配筋写真など）とメモを記録できます。
- **ドラッグ&ドロップで並び替え**：同じ物件・同じ工程内であれば、写真カードをドラッグして順番を入れ替えられます。この順番は台帳PDFの出力順にもそのまま反映されます。
- **元写真をドライブに保存**：Googleドライブ（共有ドライブも含む）デスクトップアプリの同期フォルダをローカルフォルダとして選択すると、物件名のサブフォルダに元データをそのまま保存します（OAuth設定不要。選択は初回のみで、以降は自動保存されます）。File System Access APIに対応していないブラウザでは、代わりにZIPダウンロードで同じ構成を作れます。
- **検索**：物件名・説明・撮影日・ファイル名でその場に絞り込めます。
- **台帳PDF出力（2形式）**：
  - **詳細あり**：工事番号/報告日/工事名/会社名/注文者/報告者のヘッダー + 1ページ3枚、NO/工事場所/工種/工事箇所+備考欄付きの明細フォーマット。
  - **画像のみ**：横向きA4・1ページに大きな写真2枚だけを並べる、文字情報なしのシンプルなフォーマット。
  - 出力前にツールバーのプルダウンでどちらかを選べます。
- **作成履歴**：写真の取り込み・編集・削除・並び替え・物件の追加／変更／削除・PDF出力を、担当者名・日時付きで記録します。「作成履歴」ボタンから確認できます。
- **担当者名の設定**：ヘッダーの「担当者: ...」ボタンから一度入力すれば、その端末・ブラウザでは以降も覚えていて、履歴に自動で記録されます。

## データの保存場所

台帳データ（写真・説明・物件名・履歴など）はブラウザのIndexedDBにローカル保存されます。特定のサーバーやアカウントに依存しません。重要な注意点:

- **データは端末・ブラウザごとに独立しています。** 複数のPCやブラウザで同じデータを共有することはできません（サーバーを持たない設計のため）。複数人で使う場合は、1件の台帳作業は1人がまとめて行う運用を想定しています。
- 別の端末にデータを移したい、またはバックアップを取りたい場合は、PDFやZIPでの書き出しをご利用ください。
- ブラウザのキャッシュ・サイトデータを消去すると、台帳データ（写真・メモ・履歴など）は失われます。ドライブ同期フォルダに保存した元写真は影響を受けません。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（dist/ に出力、そのまま静的ホスティング可能）
npm run lint      # oxlint
```

## 技術構成

- Vite + React + TypeScript（クライアント完結、バックエンドなし）
- `heic2any`：HEIC/HEIF → JPEG変換
- `exifr`：EXIFからの撮影日抽出
- `idb`：IndexedDBラッパー（写真・物件・設定・履歴の保存）
- `jspdf`：台帳PDF生成（日本語フォント IPAゴシック を同梱し文字化けを防止。ライセンスは `public/fonts/LICENSE.txt` 参照）
- `jszip`：Drive同期フォルダが使えないブラウザ向けのZIP書き出し
- File System Access API：Googleドライブなどの同期フォルダへの直接書き込み（対応ブラウザ: Chrome / Edge など）

## ブラウザ対応について

「ドライブ同期フォルダを選択」機能は File System Access API を使用しており、Chrome / Edge 系ブラウザで動作します。Firefox / Safari など未対応のブラウザでは、代わりに「元写真をZIPで保存」ボタンが表示され、ダウンロードしたZIPを手動でGoogleドライブの同期フォルダに入れる運用になります。
